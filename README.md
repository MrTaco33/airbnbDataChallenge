# airbnbDataChallenge
# Proyecto de Microeconometría aplicada sobre la evaluación 
# y rentabilidad de Airbnbs por colonia en la Ciudad de México

# El proyecto incluye tres componentes principales:

# 1. **Limpieza y unificación de bases de datos**
# 2. **Exploración visual y estadísticas descriptivas**
# 3. **Modelos econométricos (nivel y log-precio), con y sin controles y con efectos fijos por alcaldía**
---

## 📂 Estructura del repositorio

airbnbDataChallenge/
│
├── data/                     # Datos utilizados (raw, external, processed)
│
├── scripts/                  # Código en R
│   ├── 01_exploracion_inicial.R
│   ├── 02_visualizaciones_avanzadas.R
│   ├── 03_modelo_econometrico.R
│   └── utils y merges
│
├── figs/                     # Mapas, gráficos de densidad y boxplots
│
├── reports/                  # Resultados HTML/PNG producidos por los scripts
│
├── output/                   # Archivos exportados para el reporte final
│
├── Reporte final/            # Documento en Overleaf
│
└── README.md                 # Este archivo
